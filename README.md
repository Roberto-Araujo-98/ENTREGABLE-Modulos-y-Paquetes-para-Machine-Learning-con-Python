# ENTREGABLE - Módulos y Paquetes para Machine Learning con Python

Proyecto final enfocado en análisis de sentimiento financiero y predicción de tendencias de mercado utilizando Python y procesamiento de lenguaje natural (NLP).

## Estructura del Repositorio

* **`trabajo_final_ml.ipynb`**: Cuaderno principal con el código de entrenamiento, preprocesamiento y modelos predictivos.
* **`opiniones_financieras.csv`**: Conjunto de datos para el análisis de texto y sentimiento.
* **`tendencia_mercado.csv`**: Conjunto de datos numéricos para la predicción de tendencias.

## Tecnologías Utilizadas

* Python
* Pandas / NumPy
* Scikit-Learn
* spaCy
* Matplotlib / Seaborn
